# Dire Wolf Lite — free animated wolf

A free, game-ready version of the Dire Wolf from the Dire Wolf Pack: a huge,
rigged grey-brown wolf.

- **Mesh:** 9,991 triangles (the full pack's LOD1), 4 bone influences per vertex
- **Rig:** the full 35-bone rig, with the same bone names as the full pack
- **Animation:** 4 clips at 30 fps: idle and walk and run (all loop), bite
- **Textures:** 2K base colour, normal and metallic/roughness, embedded in the files
- **Files:** `Dire_Wolf_Lite.fbx` (Unity, Unreal) and `Dire_Wolf_Lite.glb` (Godot, web, Blender)
- **Scale:** metres; 1.3 m at the shoulder

Unity: Rig → Generic, root node `root`. Unreal: import as a Skeletal Mesh.
Godot: drop in the .glb.
