This asset is a free version of Stylized Fruit Pack Full asset.
For Full Pack: https://assetstore.unity.com/packages/3d/props/food/stylized-fruit-pack-full-156692

Your Default Render Pipeline needs to be set to URP.

Open the Demo Scene.

Go to
Project Settings → Quality → Rendering → Rendering Pipeline Asset
then drag the URP Asset (in SampleSettings folder) into the slot.
(Required for Renderer Data and Volume support.)
